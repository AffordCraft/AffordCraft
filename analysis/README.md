# Analysis: statistics and generators of the paper's tables and figures

Every table of the paper and the data figures are generated by the scripts in this folder from recorded result files;
no numeric cell is typed by hand. The generators read their inputs from `--inputs` (default `analysis/results/`) and
write LaTeX tables, PDF/PNG figures with JSON receipts, and fact files to `--out` (default `analysis/out/`, not tracked).
With the inputs included in `results/`, every table generator reproduces the manuscript's tables exactly (all 15 table
files; only the first comment line, which names the generator and its sources, differs), the figure receipts match
(size, text checks and every fact), and the prompt listing matches when it is extracted from the main campaign's code.

```bash
pip install matplotlib numpy pillow          # figures only; the table generators need the standard library alone
python analysis/tables/tables_comparison.py  # --inputs analysis/results --out analysis/out (defaults)
python analysis/figures/fig_time_to_pass.py
python analysis/stats.py                     # self-check of the statistics against recorded values
```

`figures/style.py` holds the shared palette, canvas and save routine (PDF + PNG at 400 dpi + a JSON receipt that records
the canvas size, the minimum text size, text outside the canvas, input hashes and the plotted facts; the save fails if
any text leaves the canvas). Fonts: Arial.

The failure-mode classes of `vla_failure_modes.tex` (`scenes/fig7_export/failure_modes_round2.json`) are computed from the
scene study's episode traces by `policy/scenes/vla_head/failure_modes_round2.py`. The external-method aggregate, the
clean timing summary and the API cost file come from `evaluation/`.

Statistics (`stats.py`, identical to the inline copies in the generators): 95 % Wilson score intervals; the exact
two-sided McNemar test on discordant pairs (binomial, p = 1/2); nearest-rank quantiles for the P90/P95 of the external
rows and the clean timing run; linear-interpolation quantiles for the campaign's P95/P90. No bootstrap is used.

Notes on individual outputs:
- `make_tables.py` is the generator of the development-evidence tables. The manuscript's library table
  (`catalog_details.tex`) shows its library numbers (entries, coverage, top-1 agreement, median and P95 query time) in a
  compact layout without the mean column; the other tables it writes were superseded by the generators above and go to
  `development_tables/` so that they never overwrite them.
- `prompts_appendix.py` parses the prompt expressions of `ground()` and `rank()` in `affordcraft/vision.py` and of the
  detection script. The paper's listing was extracted from the main campaign's frozen code (formal-code-009), in which
  `rank()` builds its prompt in one expression; pass that code archive with `--code <archive>.tar.gz` (members
  `method/affordcraft/vision.py`, `tools/detect_scene_objects.py`) to reproduce the appendix exactly. The repository's
  `affordcraft/vision.py` is the one-factor-study version (formal-code-010), which appends the instruction, the grounded
  part and the candidate list in separate statements (the same text when the task condition is on); run on the
  repository (`--code` = repository root, members `affordcraft/vision.py`, `scripts/detect_scene_objects.py`), the listing
  shows only the fixed part of the ranking prompt.

## Changes from the executed version

- Inputs are read from `--inputs` and outputs written to `--out` (`tables/`, `figures/`, `facts/`, `sections/`,
  `development_tables/`) instead of fixed folders of the manuscript working copy; the input files were renamed into the
  layout above. The dry-run environment overrides of `tables_comparison.py` (`AFFORDCRAFT_EXT_DIR`,
  `AFFORDCRAFT_CLEAN_DIR`, `AFFORDCRAFT_CLEAN_PARTIAL`, `AFFORDCRAFT_SIMULATE_COMPLETE`) are kept; its manuscript-folder
  override is replaced by `--out`.
- The first comment line of every generated table and a few provenance strings in the fact files name the published
  generator and input files instead of the working-copy paths and internal run names.
- `figures/style.py` saves under `OUT` (set by each figure script from `--out`) instead of the working copy.
- `prompts_appendix.py` accepts the repository layout as well as the code archive (`--code`), and reads the detection
  prompt head from `prompts/detection_prompt_head.json` instead of the whole frozen detection definition.
- `fig6_library_compact.py` keeps its optional positional arguments (name, height) next to `--inputs` / `--out`.
- Comments and docstrings: dates, names of people and machines, and references to manuscript-editing scripts
  removed. Formatting with black (AST unchanged apart from the lines above).
- Renamed (internal version suffixes dropped): `tables_ablation_014.py` -> `tables/tables_ablation.py`,
  `fig4_fig8_013.py` -> `figures/fig4_fig8.py`. Output file names are unchanged (the manuscript includes them).
- Not included: the scripts that edited the manuscript text or patched generators, build and PDF checks, page-layout
  helpers, citation and bibliography helpers, the asset-render and gallery-composition scripts (they render USD assets
  and photographs), and backup copies.
